# SolveTheory public preview

This public repository contains only a static, four-question SolveTheory SAT preview. The main SolveTheory application and its backend remain in a separate private repository.

## Enable your website

1. Go to **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then click **Save**.
4. Once GitHub reports the site as published, open **https://pvackk7.github.io/pvackk7/**.

The site includes a time-of-day theme and an interactive preview at `/demo.html`. This static demo deliberately has no account signup, leaderboard, or cloud-saved progress, because those features require a backend.
